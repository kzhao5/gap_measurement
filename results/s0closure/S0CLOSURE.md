## 1. 裸和律:形式成立,但大半是长度混杂(§8 的警告成真)

MoE:λ₀ = 0.3055 [0.243, 0.373],β₀ 效应 E_D = 0.0006(S⁰₋t 对 D_t
干净零依赖 ✓),非线性 ΔR² = 7e-5(线性形式充分 ✓)。**但**:

- **置换零基线 λ₀ = 0.247**(打乱轨迹内关联、保留边际后"斜率"仍在)——
  机制:E[D]<0 ⟹ S⁰ ∝ −T,而长轨迹系统性更不确定(u 与 T 正相关),
  长度通道冒充耦合。**真耦合 ≈ 0.305 − 0.247 ≈ 0.06**;
- T 三分层层内 λ₀ = 0.17/0.17/0.23 < 合并 0.305,同一指向;
- R² = 0.001:该律只是巨大轨迹级噪声(ω²≈4.4)上的一个微小均值漂移。

Dense:λ₀ = 0.036(≈MoE 的 1/10,与 σ 的 48× 差距同向),置换零基线
≈ 0(dense 无长度混杂,因 |E[D]| 小两个量级)——小但真。

**结论:裸和律的可用信号(去混杂后 λ₀~0.06–0.17)远小于消融最优
λ₊=2.3,与 W1′/J1 的"Δ 平坦"一致。**

## 2. 族闭合:被拒,且理由是协议预设的 Failure C

E_Δ 中位 0.52(判据 0.10),γ(Δ 对 D 的依赖)中位 0.80。但同时:
指数矩不稳定的红旗全亮——MoE 残差的 **ESS₂ = 985**(2.4M held-out token
中真正贡献 L₂ 的不到千分之一),**top 0.1% 轨迹占 L₁ 质量 21%**。
按协议 §10 Failure C:**L₂ 被极少数轨迹主导时,Δ 面不可信,不宣称闭合
也不宣称反闭合**;正确姿势是半参数(与 J1 判决相同)。
(β-回归版闭合判据 100% 通过——token 级回归对尾部不敏感,两判据
分歧本身就是"结构藏在尾部矩里"的证据。)

## 3. 不动点:收敛且(可估域内)唯一——**λ\* ≈ 0**

MoE:所有可迭代初始点 → **(C\*, λ\*) = (4.33, 0.071)**;
dense → (1.54, −0.07)。**λ\* ≈ 0 = 序列级 MSE 机器输出的是常数 cap,
不是 φ 带**——这是继 W1′(Δ 平坦)、J1(λ_eff≈0)之后的第三个独立确认,
且这次是用"把理论跑到收敛"的构造性方式得到的。

| 方法 | MoE R_n | dense R_n |
|---|---|---|
| nocorr | 2.30 | 0.233 |

| TIS (cap 2) | 0.105 | 0.0015 |

| **M\* (4.33, 0.07)** | **0.042** | 0.0015 |

理论管线优化自己的目标很成功(M\* 比 TIS 低 2.4×);dense 失配太小,
所有修正等效。注意 IcePop 行:mask 的序列权重语义(被除名 token 记
m=1)在 R_n 下近似无修正——R_n 衡量的是序列权重,不是各方法真正作用的
梯度层,横向解读要小心。

## 5. 综合(论文怎么写)

四个理论实验(W1′、J1、S0、闭合/不动点)+ RL 消融现在指向同一个结论:

- **序列层面**:耦合微弱(真 λ₀~0.06)、Δ 平坦、BR 不动点是常数 cap
  (λ\*≈0)且它确实最小化 R_n——序列级理论**自洽但产不出 φ 带**;
- **φ 带的依据在 token 层**:σ=cφ 实测律(R²≈0.999)+ 枢轴性 +
  RL 消融(仿射/双侧/下界全被否决,λ₊∈{1.6,2.3} 稳健);
- 所以论文的定位:R_n 理论给出"截断必需 + 常数 cap 形状 + C 的量级",
  φ_t 形状因子由 token 级测量与 RL 实验共同钉死。R_n 最优(常数 4.3)
  与 RL 最优(带 2.3)不同这件事本身,说明序列权重 MSE 不是 RL 成功的
  充分判据——这是一个值得写的发现。
