## 结论:token 级 MSE 亦被 RL 否证,负面证明闭环

token 级 MSE 的收敛解是**递增 cap**:高置信 token 梯度小(‖∇‖∝(1−p)),
MSE 允许它们的 cap 大到 e^13;不确定 token 梯度大,MSE 要收紧——
**与 RL 最优的 σ-TIS 递减带(不确定端带宽大)方向恰好相反**。
机理上这近乎结构定理:C(p) = n(−b)v(p)/s(p),在 C1/C2 独立性下
v/s ∝ 1/(1−p) ⟹ β=−1;实验的增量贡献是 (a) C1/C2 独立性的实证,
(b) 方向版(非结构性,含真实 ⟨−b, v⟩ 内积)同向 β=−0.88,
(c) 五起点唯一收敛与 n 不变性。

### 三层合并表(理论章收口)

| 层面 | 不动点输出 | RL 最优 |
|---|---|---|
| 序列级(S0closure) | 常数 cap (4.33, λ≈0) | — |
| token 级(本实验) | **递增 cap,β̂ = −0.97** | — |
| RL 收兵 | — | **λ₊=2.3 递减带** |

两级 MSE 理论跑到收敛,给出的形状一个是常数、一个是递增——都不是
RL 赢家的递减带。**MSE 家族(无论序列级还是 token 级)不产出 φ 带;
φ 带的依据只能来自:σ=cφ 实测律 + 枢轴性 + RL 消融。** 这为论文的
理论章提供了干净的"排除法"结构:什么推不出带形,和什么推得出,
都有实验背书。
