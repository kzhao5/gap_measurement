## 判决(§9 判决表)

命中**第四行为主、第三行不排除**:

1. **均值通道路线被决定性否证**:λ_eff 与 λ_semi 都 ≈0 或弱负,与 +λ₊=2.3
   相差悬殊、符号不符 ⟹ **λ₊φ_t 带形不能由序列 MSE(非独立 FOC)推出**,
   其依据留在 E2 实测(σ=cφ)+ (Z1) 枢轴性;
2. **(W1) 一阶近似成立**:最大数据集(20k 轨迹,标定 c 的同一批)上
   Δ(φ) 斜率 −0.002 [−0.32, 0.13] —— **平坦,常数 cap 在序列层面站得住**;
3. 批间存在向弱负的波动(批1 −0.57 显著、批2 −0.17 n.s.)——方差通道
   "低置信端更紧"的方向不排除,但幅度即便取最负的批也只有 λ₊ 的 ~25%,
   是二阶效应;论文如实报告为敏感性/批间变异;
4. β₁≈1.8 三批稳定显著:**均值耦合本身真实存在**(不确定 token 多的轨迹,
   其余部分对数权重和更低),只是被方差通道近抵消——这是 §0 预言的
   "两通道符号相反"的直接实证。

与 RL 消融交叉验证:仿射带 η=0.12(加宽)被否决(62.85% vs 64.67%)、
更紧的 λ₊=1.6 与 2.3 同层——与"Δ 平坦或弱负、绝不更宽"一致。
