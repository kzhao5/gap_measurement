## E1. 直接测量 δ（logit 扰动本身）

**老师原话**

> "那我就（建议）从真实数据里提取出这个 δ 来，然后说一下它的（统计）性质。"

**为什么必须做**

现在全篇只测了 ε（采样 token 的 log-odds 位移），δ 从未被观测过。但 Definition 4.1 的两条性质（零均值、与置信度独立）本质上是**关于 δ 的断言**，Lemma 4.2 只是把 δ 换算成 ε 的恒等式。不测 δ，这两条就永远是假设。

**做法**

在现有静态测量流程（Appendix B.1）上扩展：不再只存采样 token 的 log-prob，而是**dump 两个引擎的完整 pre-softmax logit 向量并相减**。

- 规模不用大：现有是 12.3M token，这里 **200–500 条序列、每条取若干位置**就够画分布。瓶颈是显存和 IO（V ≈ 150k 的 float 向量）。
- 可以只 dump 最后一层 logit（δ 的定义就在这一层），不需要逐层。
- 沿用 B.1 的控制条件：vLLM 0.26 / bf16 / eager / 无 prefix caching，训练引擎 teacher forcing 同一 snapshot。
- **对照组照做**：dense（Qwen1.5-14B-Chat）和 MoE（Qwen1.5-MoE-A2.7B-Chat）都要测，这是 E2 的关键。

**要看的三件事**

| 检查项 | 预期 | 用途 |
|---|---|---|
| `E[δⱼ] = 0`？ | 是 | 支撑 Definition 4.1 补写的零均值 |
| `δⱼ` 的尺度是否 ∝ `\|zⱼ\|`？ | 是（相对精度固定） | 说明它是舍入噪声而非别的 |
| `δ` 的分布是否随 `p_t` 变化？ | 否 | **这是 Remark 4.3 独立性的直接证据** |

**输出物**：Figure 1(b) 的数据；§4.1 新增段落的实证支撑。

**工作量**：中。主要是改 dump 逻辑 + 存储，计算量很小（不需要训练）。

💡 **顺带查一件事**：Figure 1 的 bin width 是 0.125，而 bf16 在 logit 典型量级（16–32）上的格点间距恰好是 `2⁴×2⁻⁷ = 0.125`。去看一下 δ 或 ε 的取值是不是贴着 bf16 格点走的（直方图会呈现梳齿状）。如果是，这是一张极有说服力的图——直接把数值噪声和浮点格式钉死。如果只是巧合，换个 bin width 免得误导审稿人。

## E2. 用舍入模型算 μ，与实测对照（dense 做验证场）

**老师原话**

> "你把这个 rounding 的噪声，去 validate 一下你那个 068 那里的 μ。……你把 μ 算一下，然后跟那边的这个（实测值）对一下。如果能对出来的话，那我觉得也差不多了。"

**做法**

1. 从舍入模型解析地推 μ：设 `δⱼ = ηⱼ·|zⱼ|`，`ηⱼ` 零均值、`|ηⱼ| ≤ u`（bf16 的 `u = 2⁻⁸`）、与 z 独立。代入 Lemma 4.2 小扰动展开得

   $$\varepsilon_t \approx -\delta_{y_t} + \sum_{j\neq y_t} w_j \delta_j,\qquad \mathbb{E}[\varepsilon]=0,\quad \operatorname{Var}(\varepsilon)\approx \sigma_\delta^2\Big(1+\textstyle\sum_j w_j^2\Big)$$

   再由 `μ = E[e^ε] ≈ exp(σ_ε²/2)` 得到理论值。
2. 与 Figure 2 在 α=1 处的实测 μ 对照。
3. 用 E1 实测的 `σ_δ` 反推 `σ_ε`，和直接测的 ε 方差交叉验证。

**⚠️ 这里要注意结果怎么写**

**不要指望舍入模型能算出 MoE 的 μ = 7.07。** `μ ≈ exp(σ²/2) = 7.07` 需要 `σ ≈ 2.0`，远超舍入噪声能产生的量级。也就是说 μ = 7.07 是被**尾巴**撑起来的，不是被主体撑起来的。

这和你自己的数据完全一致：dense `ξ₊ = 0.07`（轻尾）、MoE `ξ₊ = 0.49`（重尾）；dense `c = 0.035`、MoE `c = 0.155`；残差 token 在硬路由翻转上富集 1.46 倍。

所以**正确的汇报方式是两段式**，而且这比硬凑一个数强得多：

- **主体（scale channel）= rounding。** 拿 **dense 模型当验证场**——那里没有路由，是干净的对照组。舍入模型应该能预测出 `c ≈ 0.035` 的量级和接近 1 的 μ。这一段是"对上了"。
- **重尾（residual channel）= 路由翻转。** MoE 的 μ = 7.07、`ξ₊ = 0.49` 超出舍入模型预测，超出部分归因于路由。这一段是"没对上"——**而没对上才是论文要的结论**：它证明第二个 channel 真实存在，正是它让 truncation 从"可选"变成"必需"（呼应 Appendix B.4"MoE 尾巴重，所以截断是必要而非可选"那句）。

老师留的口子正是这个：*"floating point 不是唯一的原因，但是你至少能够从 floating point introduce 进来，这个东西是 reasonable 的。"*

**输出物**：§4.1 的推导 + 一张 dense/MoE 对照的小表（理论 μ vs 实测 μ、理论 c vs 实测 c）。

**工作量**：低（主要是推导 + 用 E1 的数据算），不需要新跑训练。

## E3. 受控噪声注入的 dose–response 消融 ⭐ 本次唯一的新实验要求

**老师原话**

> "你要不 simulate 一些，可能有个 ablation：你把这个 μ 变大一点。你那边不是引了一个 δ 进来吗？你得手动加一个可控的信号——可以控制的 δ。"
>
> "就看你的那个 δ 怎么控制：rounding 可能并不是以 10 为底的 rounding，它可能是 fp8 的 rounding。所以你要做消融，可能是要拿那个东西做调——就是把它 round 到 fp8，或者甚至是 aggressive 一点、fp4。"

**这是整条逻辑线的收尾**：既然方法的收益由 μ 决定（Theorem 4.4 的 `E[e^{2ε}]` vs Theorem 4.6 的 `(1+λ)μ`），那就**主动把 μ 推大**，看 CIS 相对基线的优势是否按理论预期增长。这是可证伪的因果证据，比再刷一个 benchmark 值钱得多。

**做法**

在推理引擎的 logit 上（或 KV cache 上）注入可控量化噪声，分 3–4 档逐级 aggressive：

| 档位 | 注入方式 | 预期 `u` | 预期 μ |
|---|---|---|---|
| 0（基线） | 原生 bf16 | 2⁻⁸ | 7.07（已测） |
| 1 | round 到 fp8 (e4m3) | 2⁻⁴ | ↑ |
| 2 | round 到 fp8 (e5m2) | 2⁻³ | ↑↑ |
| 3 | round 到 fp4 / 可调步长 | 更大 | ↑↑↑ |

每档记录：

- **诊断量**：实测 `μ = E[e^ε]`、`E[e^{2ε}]`、scale 常数 `c`、尾指数 `ξ₊`
- **训练结果**：各算子（无校正 / exact ratio / TIS / IcePop / KPop† / CIS）的 GSM8K held-out 精度、training reward、intervened 比例
- **CIS 特有**：按 `λ₊ = cτ⋆` 重新编译的 slope 是否仍落在 plateau 上

**预期结论（三条，都可证伪）**

1. μ 随量化变粗单调上升，且上升幅度与舍入模型预测一致 → 反过来验证 E2 的机制。
2. exact ratio 的退化随 μ 增长最快（它的方差含 `E[e^{2ε}]`），CIS 退化最慢（只含 `(1+λ)μ`）→ **这是 Theorem 4.6 的直接实验验证**，目前论文里没有任何一个实验在验证"指数从 2 降到 1"这件事。
3. 按测得的 c 重编译 slope 能恢复大部分损失 → 把 §5.4 的 FP8 单点结果推广成一条曲线。

**与现有 FP8 实验的关系**

**不是一回事，但可以互相印证。** §5.4 (Table 2 右) 是换 serving 配置后**被动观察** c 从 0.60 涨到 1.75；老师要的是**主动、可控、分档**注入。现有的 FP8 KV-cache 那一行正好是这条新曲线上已有的一个点，可以直接并进来，省一档的工作量。

**工作量**：**高，这是最大的一块。** 每档要跑一轮完整训练（论文里单 arm 1.3–3.5 小时 / 8×A100）。建议压缩：

- 只跑关键的 3 个算子（无校正、exact ratio、CIS），不用全跑六个
- 每档单 seed，明确标注为单 seed（论文里 §5.4 已有这个先例："The comparison is single-seed and we report it as such"）
- 3 档 × 3 算子 = 9 个 run ≈ 1–1.5 天

💡 **可以先做零成本的预演**：诊断量（μ、c、ξ₊）不需要训练，只要在静态测量流程上加一层量化就能算。**先把 μ vs 量化档位的曲线画出来**，确认量级动得够明显（μ 至少要涨一个数量级才有说服力），再决定投多少卡去跑训练。如果 μ 动不起来，这个消融就没意义，早发现早止损。
