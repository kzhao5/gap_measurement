## 三个高价值发现

① **B 的真实形态(lag-29 配对,直接观测)**:整体近对称(ρ₊=0.49)+
**低置信端系统性负移**(中位 B 从高置信 ~0 降到低置信 −0.67——策略锐化:
新策略把不确定 token 的概率进一步收走)+ **重正尾**(q99=+0.68,
q999=+2.15)。"B≥0 恒正加性"是错的;对的是"两侧位移、只有正尾危险"。

② **威胁模型的正确修订(与 RL 消融自洽闭合)**:算子单侧性的依据从来
不是"B 恒正",而是**伤害不对称**——B<0 使 k 变小 → 自消音,天然无害
(下界消融的剂量反应正是实证);B>0 的重正尾使 k 爆炸 → 必须 cap,
而 H 实验证明 **σ-TIS 的 cap 正好 10× 富集地打在污染 token 上**。
修订后的 threat model(两侧 B + 正尾控制 + 自消音左侧)与全部 RL 证据
一致,且理论 λ 闭环到 2× 内。

③ **训练后策略的干净失配尺度 c = 0.52(基线模型的 3.3×)**:RL 训练
放大数值失配(锐化+漂移),(1−p) 律形式不变(R²=0.996)。含义:失配
问题随训练**加重**,修正算子越训越重要;论文可作为"为什么小失配起点
也要修正"的证据。

## 效度边界

- 配对 lag 单位是 epoch(29/58 步)——比真实 rollout lag(1-2 步)粗;
  真实 lag 的组级证据(G:加性胜;F:ε=0.48%)与配对证据互补,
  两个尺度上的结论各自陈述,不外推;
- kt-dump 无 traj/pos 结构 → 污染聚簇性(Lift)不可测,定理如需
  clustering 假设须显式声明;
- 单臂(lg0)、单任务。
