# 跨置信层梯度相干性矩阵 — 收口报告

协议:`gradient_coherence_guide.md`。数据:campaign 全 8 shard 收割
(g_proj 128 维 + h_proj 32 维),带符号 A≠0 的有效 token **2.18M**
(打分 acc 4.6%,20.4% 轨迹携带优势)。16 等质量 p 桶。

## 预注册判读:中间态(远层校正 |Coh| = 0.392 ∈ (0.2, 0.5))

按预注册以衰减校正后的远层(|b−b′|≥4)质量加权中位数为判读数:
L1 = 0.392,L2 = 0.384 → **中间态:报告矩阵本身,两条理论线并列,
以 RL 收兵为裁判**。

## 但噪声地板分析显示证据向 (D) 倾斜

| 量 | L1 | L2 |
|---|---|---|
| 远层 raw \|Coh\| | 0.100(bootstrap CI [0.071, 0.139]) | 0.066 |
| 置换零分布 q95 | 0.105 → **未出零分布** | 0.054 → 勉强出(1.2×) |
| 半分自洽 self(b) | 大多 0.1–0.4,min<0 | 同 |

关键:**几乎所有桶的半分自洽 < 0.5**——按协议 §3a 的自判标准,
"层均值本身没测准",衰减校正(除以 √(self·self′) ≈ 除以 0.1–0.3)
把噪声放大,0.392 应视为**不可靠的上界**而非测量值。可靠的陈述是:
**远层原始相干 ≈ 0.10,与纯噪声地板统计不可区分(L1)或勉强可区分
(L2);数据与远层方向多样性 (D) 一致,相干性上界 ~0.14(CI 上沿)。**

## 结构发现(免费但重要)

1. **带状矩阵实锤**:距离衰减 lag1 ≈ 0.31/0.27(显著出零分布)→
   lag4 ≈ 0.14 → lag15 ≈ 0.01-0.04。**近邻相干、远层趋零**——协议 §5
   预言的"最可能真实形态";二分定理的"分层"应作粗粒度层理解,
   (D) 在粗尺度成立即可。
2. **ρ(p) ≈ 0.004–0.007(全桶)**:桶内单 token 方向与层均值的相干只有
   ~0.5%!token 级梯度方向几乎完全多样——这一并解释了 (a) 层均值为何
   难测准(self 低),(b) token 不动点实验中方向版为何欠功率,
   (c) 范数版 ρ=1 假设离真实有多远。
3. **符号是关键**:|A| 加权版远层校正值 0.55、仅正优势版 0.59——
   **不带符号的"幅度方向"跨层相干,带符号的"更新方向"不相干**。
   优势符号翻转是摧毁跨层相干的主因,这正是协议 §4 坚持保留符号的理由。

## 判决落地方式(与 §7 对表)

- 预注册中间态 → 按协议交矩阵 + 两线并列,**RL 收兵为裁判**:RL 已裁
  (递减带赢),叠加本测量的"(D) 倾斜"读数,MSE-with-(D) 推出递减带的
  正面推导线获得**弱支持但未达确证**;
- 确证路径(协议 §3a 的处方):加倍有效样本。现成方案:污染实验正在
  生成的 GSM8K 配对 rollout(打分 acc 高一个数量级 → 有效 token 密度
  远高于 DAPO)上补一次 g/h 收割即可(≈10 分钟 GPU);
- token 不动点的范数版结论(β=−0.97)在 ρ≈0.005 面前需降权:它测的是
  "假设完全相干"分支的形状;真实 ρ 极低,方向版/二分定理路线才是主线。
